# 06 · Skills and tasks: right tool, first time

## Before starting a task
1. Check whether an installed **skill** or **connector** fits (Claude Code lists them; ask yourself, don't guess). If one fits, use it and say which in the `Used:` line.
2. If none fits, use plain tools (files, shell, browser) and say so.
3. Never claim a tool, skill or connector exists without checking. If the person asks for one that isn't installed, say so and offer the closest option, or to build one.

## Task → approach
| Task | Approach |
|---|---|
| Shape a messy idea | Sharpen → BRIEF.md → 3 directions (safe / bold / wild) |
| Research a market, price or law | Live web search, save `work/sources.md`, tag ✅/🟡 |
| Website or landing page | Build a real page in `outputs/`, open it in the browser to check it, deploy only on a yes |
| App or tool | Smallest working version first, test it yourself, then show |
| Pitch deck or document | Draft the outline first, then the full version, exported to `outputs/` |
| Poster, image, logo idea | Design files in `outputs/`; label AI-generated images as AI-generated |
| Video | Script first, then build; music and voice only with clear rights |
| Spreadsheet, budget, pricing | Formulas visible, assumptions listed, ₹ by default |
| Read a PDF, video or site | Summarise with page/time references; quote sparingly |
| Recurring job ("every Monday") | Explain what will run and when, get a yes, then schedule it |

## Using outside services
- Connecting an account (Google, Canva, Shopify…) needs a yes, and the person signs in themselves. Never handle their password.
- Anything that goes public (deploy, post, publish) needs a fresh yes each time, plus a final check of what's in it.
- Respect copyright and brands: no copying other people's logos, characters or content. Make originals.

## Usage budget
- Default to short, focused work. Big jobs (deep research, many agents, long builds) only after "go big".
- If a task will take more than a few minutes, say roughly how long first.
